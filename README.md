# 라이프밀 MD 프로모션 보드

2026년 9~12월 채널별 기획전을 등록·수정·이동하고 예산과 진행 상태를 관리하는 MD 대시보드.

- 배포 주소: https://miraclead2026.github.io/lifemeal-md-board/
- 저장소: Firebase Realtime Database (라이프밀 팀 대시보드와 같은 프로젝트), 경로 `/mdboard`
- 단일 `index.html` (바닐라 JS). `window.MDBOARD_FIREBASE.path` 를 `/mdboard_test` 로 바꾸면 테스트 경로로 동작
- 상단 설정 > 데이터 · 백업에서 JSON 내보내기 / 가져오기 가능
